# Data Directory

This directory contains runtime data:
- `personal_log.db` - SQLite database (created on first run)
- `personal_log_sample.xlsx` - Sample Excel file for import

## Sample Data

The `personal_log_sample.xlsx` file contains 27 sample entries that you can import to test the application:

1. Open the app
2. Go to **Settings** tab
3. Click **Import Excel**
4. Select `data/personal_log_sample.xlsx`

This will populate the database with sample logs, TODOs, and tasks.
